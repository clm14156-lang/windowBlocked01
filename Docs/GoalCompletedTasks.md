# 已完成的任务弹窗

弹窗按新设计改为 600 × 590 DIP，在原 800 × 710 窗口内居中展示。统一白底、14 DIP 圆角、浅灰描边和极轻阴影。标题为「已完成的任务」，下方为「全部／今天／本周／本月」四个筛选按钮及靠右的「共 X 项」。默认选择全部，选中为橙色、白色文字，其他按钮为白底浅灰描边。

已移除搜索框、搜索逻辑、日期分组及其标题、计数胶囊、折叠按钮和相关展示模型。列表只有固定表头「任务内容／完成时间」，每个已完成父任务是一条 48 DIP 高的独立行，包含橙色方形完成标记、任务名称、本地完成日期和时间；行间使用极浅灰分割线。备注和子任务保留在原始任务数据中，扁平列表不额外展开层级。长任务名称省略显示并可悬停查看完整名称。

数据继续来自当前目标下的真实已完成任务，经 TaskCompletionPolicy 校验并按任务 ID 去重。弹窗数量为当前筛选结果数量；目标页已完成任务卡片与 SummaryDisplay 仍使用全部任务总数。更换筛选不会改变目标页统计或历史专注记录。

筛选使用现有本地时钟提供器：今天按本地零点到次日零点，本周按周一零点到下周一零点，本月按自然月边界，均为左闭右开区间。以 CompletedAtUtc 转成本地时间后判断，不使用创建日期或更新时间代替。缺少完成时间的旧任务仍出现在全部中，时间显示「—」，不加入有日期范围的筛选；在两种排序方向中均置于末尾。

打开弹窗默认全部、按完成时间从新到旧。点击「完成时间」表头可切换从旧到新，再次点击恢复从新到旧；表头箭头与提示文字同步更新。排序比较完整时间戳，显示精度为分钟；同一时间按原任务顺序和 ID 稳定排列。筛选或排序后列表滚回顶部，表头与按钮固定不动。同一目标的数据刷新保留当前筛选、排序，更换目标或重新打开恢复默认状态。

恢复／删除能力保留在任务行的右键菜单中，亦可通过键盘上下移动到任务后按菜单键或 Shift+F10 打开。它们继续使用原有 MutationHandler、原始任务及子任务数据、并发保护和失败反馈，不改变专注计时或已保存的专注记录。关闭按钮、Esc 和点击遮罩关闭沿用现有交互。

列表使用 WPF 原生回收式虚拟化与像素滚动，避免将全部任务同时创建为 UI 控件。已验证 240 项数据的筛选、排序、数量刷新、内部滚动及容器回收；原 800 × 710 和扩大窗口下均无裁切，默认可展示约 8 条完整记录。另覆盖周跨年、闰月、本地零点边界、缺少完成时间、任务去重、历史详情保留与恢复／删除失败等情况。渲染预览使用隔离验证数据，应用实现没有内置设计稿演示任务。

本次隔离构建为 0 警告、0 错误，相关验证共 48 项通过、0 项失败，其中包含实际 WPF 窗口、UI Automation 筛选、菜单绑定与自动关闭，以及既有的服务保存／失败回滚、专注计时和任务一致性检查。总览、目标子页面在相同快照下的前后渲染 PNG SHA-256 均保持一致。筛选、排序、列表数据刷新及弹窗关闭会同步关闭任务菜单，避免容器回收后继续操作旧记录。
