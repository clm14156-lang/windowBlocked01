# 登录后自动识别会员

2026-11-04：客户端的本地 Service 已内置当前服务器的公开会员验证公钥。首次使用无需下载会员证书、运行公钥安装脚本或写入 ProgramData。Desktop 和 Service 应一起升级。

登录成功后，客户端自动向服务器获取绑定账号、设备和会话的签名权益凭证，由 Service 验证并启用当前账号的会员权益。公钥不会授予 VIP；普通账号、到期或撤销的授权仍按服务器返回的资格处理。账号切换、退出和离线凭证有效期保持原有逻辑。

当前内置公钥 ID 为 `0b0ff1ca8b3c93ecd0cf2b7a907e4193216d7715cf51d383c757247f9d5f3227`，仅用于 `http://localhost:5080/` 与 `https://192.168.1.5:5081/`。发布时应将 `src/FocusApp.Service/Config/MembershipTrust.json` 换为对应部署的公开公钥和 API 范围，绝不能包含服务器私钥。公钥作为程序集资源发布，不依赖安装目录中的可写 JSON 文件；客户端也不会自动信任网络接口返回的任意新公钥。

`%ProgramData%\FocusTime.ServerTrust` 目录不存在时使用内置信任。如果管理员创建了这个目录，则其中受保护的 `entitlement-trust.json` 完整覆盖内置信任，以便配置其他服务器、轮换或撤销公钥；空列表会禁用全部信任。文件缺失、格式错误、权限不安全或路径为重解析点均不回退到内置公钥。要恢复默认发布配置，由管理员移除整个覆盖目录。

局域网服务器的 HTTPS 自签名证书属于连接层信任，仍沿用原局域网配置；它和会员公钥是两套独立用途。用户已配置 HTTPS 的电脑升级客户端后，无需再安装会员公钥。正式部署应通过系统信任的 HTTPS 证书提供连接。
