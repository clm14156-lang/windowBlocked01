# 登录后自动识别会员

客户端的本地 Service 内置了本机开发实例和已配置局域网实例的公开会员验证公钥。Desktop 和 Service 应一起升级。

登录成功后，客户端向服务器获取绑定账号、设备和会话的签名权益凭证，由 Service 验证并启用对应权益。会员离线凭证最长有效 7 天，并受真实会员及登录会话截止时间限制。客户端每 24 小时校验，网络恢复或授权进入 48 小时续签窗口时提前校验。授权过期或本地时间明显回拨时需要联网验证。服务端签发的普通或到期凭证会立即覆盖先前的授权。

内置信任按 API 地址区分。本机 5082 实例支持 `http://localhost:5082/` 和 `http://127.0.0.1:5082/`，原有 5080 和局域网实例使用各自的受信公钥。部署配置见 `src/FocusApp.Service/Config/MembershipTrust.json`。程序集只包含固定范围的公开公钥，私钥由服务器保管。

`%ProgramData%\FocusTime.ServerTrust` 目录不存在时使用内置信任。如果管理员创建了这个目录，则其中受保护的 `entitlement-trust.json` 完整覆盖内置信任，以便配置其他服务器、轮换或撤销公钥；空列表会禁用全部信任。文件缺失、格式错误、权限不安全或路径为重解析点均不回退到内置公钥。要恢复默认发布配置，由管理员移除整个覆盖目录。

局域网服务器的 HTTPS 自签名证书属于连接层信任，仍沿用原局域网配置；它和会员公钥是两套独立用途。用户已配置 HTTPS 的电脑升级客户端后，无需再安装会员公钥。正式部署应通过系统信任的 HTTPS 证书提供连接。
