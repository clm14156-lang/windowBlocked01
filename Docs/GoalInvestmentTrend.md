# 目标投入趋势弹窗

弹窗为 700 × 448 DIP，外层圆角沿用 18。顶部保留目标名称、投入趋势说明与关闭按钮；右侧为等宽的“近7天 / 近30天 / 按月”圆角分段选择器。按月继续打开已有的月份选择浮层，沿用有数据月份与年份导航规则。

统计卡片位于顶部下方，四张等宽排列，间距 8 DIP，高度 84 DIP，圆角 12，背景 `#F7F7F9`。卡片依次显示累计投入、日均投入、活跃天数、最长单日。标题、单位、按钮和坐标刻度使用现有 Typography；统计数字使用现有 DataValueLarge，长时长只在卡片内部缩小以防止溢出。

统计口径：

- 累计投入：当前选择范围内的投入，复用 `PeriodInvestment`，不显示目标全历史累计。
- 日均投入：当前范围累计分钟数除以活跃天数，四舍五入到整分钟；无活跃日为 0。例如 156 分钟 / 4 天 = 39 分钟。使用独立的 `DailyAverageInvestment`，保留原有按专注次数计算的 `AverageInvestment`。
- 活跃天数：沿用已有的真实开始/结束时间和按日范围相交计算。
- 最长单日：当前范围内先汇总同一天全部专注记录，再取最大值，使用 `LongestDayInvestment`。复用柱状图每日汇总，跨午夜、跨月按真实时间裁切。

图表下移到统计卡片下方，保留按天展示、原有自适应纵轴、范围切换、月份选择和柱内悬停提示。图表宽 642 DIP，绘图区横向范围 48～636，顶部/底部仍为 20～146；七日柱宽最大 40，长范围按槽位自动缩窄。柱顶圆角 5，底部平直，填充为 `#FFA45D` 至 `#FFEBDD` 的橙色渐变。刻度为现有 Secondary 12，灰色加深至 `#6E6E73`；水平虚线 `#E6E8EE`，纵轴与基线 `#D3D7E0`。图表标题右侧展示“按天”，按月时同时显示所选月份。

悬停提示沿用图表坐标定位，随着新布局同步移动；不改变任务数量、专注时长或月份选择的业务行为。验证覆盖所选范围统计、同日多次专注、跨日/跨月裁切、空数据、四卡等宽与间距、月份浮层、柱状图和悬停提示；另以应用级资源环境渲染核对实际文字与选中颜色。
