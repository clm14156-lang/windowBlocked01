# 专注结束页的记录状态

深浅主题的结束页共用统计区下方、底部操作按钮上方的胶囊状态栏，尺寸为最小宽 176、高 34 DIP。新增状态栏不改变原有图片、计时、统计和底部按钮的位置。云朵勾选为绿色、同步双箭头为蓝色、硬盘为灰白或主题适配的灰色。同步图标缓慢旋转，离开同步状态或结束页时停止。

状态与当前记录的真实 session ID 绑定：

- 本地文件可靠落盘或本地服务确认保存后，显示“已保存至本地”。强制专注使用已经持久化的权威完成快照。
- 当前记录真正进入上传请求时显示“正在同步...”。其他记录上传、下载或云端连接正常均不改变当前记录的状态。
- 只有当前记录及操作 ID 对应的 `applied` / `duplicate` 回执包含有效服务器版本，且本地确认写入上传回执后，才显示“已同步至云端”。
- 上传超时、失败或回执写入失败回到“已保存至本地”。原有上传队列继续保留并重试，下一次真实请求再次显示同步中。
- 未登录的记录维持本地状态，不自动导入或改变原有归属确认规则。

真正落盘之前不展示成功状态。本地写入失败沿用现有的保存警告及“重试保存”入口；恢复文件写入已移到异步工作线程，不能阻塞结束页。可靠的恢复文件也属于本地保存，等待本地服务入库时仍保留原有恢复警告。

退出应用时等待已经启动的磁盘写入完成，避免异步落盘被进程退出截断；此步骤不等待网络或 UI 回调。

记录状态缓存有上限，并按记录 ID 和操作 ID 隔离。晚到的其他记录、旧账号或旧上传操作回执不能改变当前结果；已经成功确认的结果不会被晚到的本地保存通知降级。不增加新的云端接口、弹窗或 Toast，也不改动现有同步和本地数据归属机制。

验证使用隔离的 SQLite、Named Pipe 和可控上传回执，覆盖普通与权威强制会话、上传失败重试、未登录记录、其他记录回执、账号切换、无效服务器版本、落盘失败与恢复及退出写入保护。24 项相关检查通过；另有 4 项已有结束页测试仍预期旧的 120 DIP 倒计时字号，而现有页面使用 100 DIP，已在修改前构建复现，按修改范围保持现有字号。
