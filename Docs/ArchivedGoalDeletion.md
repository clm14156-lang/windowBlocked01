# 归档目标永久删除

归档目标菜单显示线性恢复、垃圾桶图标。选择删除只打开居中的 350×250 确认框，不立即修改数据。取消、点击遮罩或 Escape 均保留目标；删除进行中禁用重复确认和取消。

确认后，桌面端先通过既有 `targets.delete` 请求等待服务写入成功，再移除界面投影。失败保留目标及确认框并显示错误，允许重试。正在准备或进行专注的目标不能删除，以免后续计时写入重新产生记录。

数据库在同一个事务内：

- 删除该目标的全部专注会话，通过外键级联删除完成任务快照、描述/子任务快照及会话内的网站、应用规则快照。
- 删除目标，通过外键级联删除任务和子任务。
- 清除自动规则对该目标的关联，保留规则本身；清除当前选中目标的持久化引用。

任意一步失败则整体回滚。其他目标、自由专注记录、全局屏蔽规则、专注时长预设和月目标均保留。

服务返回并广播新快照。桌面端使用同一快照刷新总览、日历、目标详情、已完成任务、投入趋势、任务选择器与自动规则目标列表；累计投入、完成任务数、专注天数重新从剩余记录计算。纯内存模式同样移除任务快照并重新计算投影。

验证覆盖取消不删除、失败保留及重试、并发确认、已恢复目标的旧确认、SQLite 中途失败回滚、子表级联、服务端到桌面端刷新，以及服务重启后不恢复已删除数据。所有持久化测试使用独立临时数据库，不修改用户数据。
