# 白天专注背景渐变

浅色专注页使用现有 `focusPage/a1.png`（白天）、`a2.png`（午后）、`a3.png`（黄昏）。
三张图片均为 1448 × 1086，DPI 相同，山脊、树木和前景花草的位置一致。
背景层统一放入 `FocusSceneBackgroundPanel`，以完整素材中前景草地弧顶（约 x=800/1448）为水平锚点，平移至视口中央。
三层共享相同的等比缩放、平移及底部对齐；宽窗口使用覆盖视口所需的最小等比放大，避免平移后露出边缘。
保持素材原始宽高比与高质量缩放，不修改源图，也不使用固定裁剪素材。
已检查 25%、75% 混合画面，没有场景轮廓错位产生的重影。

## 进度与合成

直接复用 `FocusSessionViewModel.RemainingProgress`，不创建计时器或独立动画时钟。
该属性由现有本地计时引擎或后台强制专注会话提供，保留秒以下精度。
令 `p = clamp(1 - RemainingProgress, 0, 1)`：

- a1 始终作为不透明底图。
- a2 透明度为 `clamp(2p, 0, 1)`。
- a3 透明度为 `clamp(2p - 1, 0, 1)`。

因此 0% 为纯 a1，25% 为 a1/a2 各半，50% 为纯 a2，75% 为 a2/a3 各半，100% 为纯 a3。
上一张保持不透明，下一张逐渐覆盖，避免两层同时降低透明度导致背景底色透出。
渐变期间保持图片源固定，仅改变透明度；a2、a3 通过 `CacheOption="OnLoad"` 加载。

周期完全由计划时长决定：5 分钟在 2 分 30 秒达到 a2，5 分钟达到 a3；
60 分钟在 30 分钟达到 a2，60 分钟达到 a3。准备倒计时不计入渐变。
结束确认暂停时进度冻结，继续后从同一点恢复；重新开始/再次专注重置至 a1。
浅色结算页固定显示 a1：自然完成和提前结束进入结算后均隐藏 a2、a3 渐变层，
保留会话的实际计时进度，不修改结算数据或其他界面元素。
恢复窗口或重建页面直接显示当前会话进度，不从头播放渐变。

暗色主题使用 `dark_background02.png`，与 a1/a2/a3 同为 1448×1086、相同 DPI 及地面轮廓，
复用同一草地弧顶锚点、等比缩放和平移规则，隐藏 a2、a3 两层。主题切换不修改会话进度。
角色、角色阴影与动画、落叶、字体、UI 布局、任务及计时业务逻辑保持原有实现。
