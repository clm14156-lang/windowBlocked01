# 统计日历右侧详情

右侧使用固定的日期、星期、当天累计时长和 00–24 时间轴，下方仅记录列表滚动。记录按开始时间倒序展示；时间段与记录共用 `CalendarRecordInteractionState`，点击时间段会选中并滚动到记录，点击记录或按 Enter/Space 展开、收起任务。

`CalendarDayRecordViewModel` 是已有历史记录的只读展示层，不改变 `SelectedDayRecords`、统计计算、持久化或任务完成逻辑。时长使用保存的有效专注时长；累计时长沿用当天统计。间隔取较晚记录的真实开始时间减去相邻较早记录的真实结束时间，与目标页共用 `FocusRecordTimelineRules`：达到 5 分钟才显示灰色间隔圆点、连接线和文字；不足 5 分钟（含首尾相接和重叠）省略整个间隔行，用橙色线段保持相邻记录的连续分组，展开任务时随内容高度延伸。阈值使用完整时间精度判断，不先取整分钟。没有目标时省略目标行，没有父任务时省略数量和箭头。父任务按保存的任务 ID 去重，子任务读取历史快照的完整完成状态并保持缩进。

`CalendarDayRecordView` 使用 13px 橙色圆点、1.5px 连接线、15px 时间范围、12px 目标/任务、11px 摘要与间隔；父任务为 16px 方形勾选框，子任务为 16px 圆形勾选框。完成项变灰并加删除线。日期为 17px，当天累计时长为 16px。列表滚动条可见滑块为 3px。

折叠记录上下各保留 3px 边距，目标行底部不额外留白；可见间隔行固定 26px，圆点与文字在同一个 Grid 中垂直居中。移除记录底部与间隔行底部的横向分隔线。短间隔橙线穿过行边距保持连续分组，但在上下橙色圆点边缘各留约 2 DIP 微小间隙；记录行高度保持原样。没有相邻短间隔时，详情橙线仍终止于本条可见文字内容的底部以内，任务展开时随内容伸展并收回最后一行的底部留白。选中背景为中性浅灰 `#F7F8FA`。卡片尺寸、日期与时间轴位置、文字字号和业务逻辑保持不变。

展开/收起使用 WPF 原生高度、透明度和箭头旋转动画：180ms，`SineEase/EaseInOut`。橙色连接线由布局自动随内容高度变化。动画结束、页面隐藏或卸载时清除动画时钟，卸载时解绑属性通知；遵循系统关闭动画的设置。没有逐帧事件或业务定时器。时间轴的内联模式只在本日历页面启用，其他页面保持原来的时间轴行为。
