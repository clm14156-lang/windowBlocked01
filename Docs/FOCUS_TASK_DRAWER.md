# 专注任务侧栏

## 布局与交互

- 主窗口保持原有 800 × 710 专注区域。打开「查看任务」时向右扩展至 1070 × 710，任务展开 / 收起始终保持 1070 × 710；侧栏关闭后恢复 800 × 710；倒计时、背景、标题栏和结束专注按钮的位置不变。
- 任务侧栏为 270 × 710，白色、直边、无投影，左侧使用 1 px 浅色分隔线。顶部 60 px，底部「+ 添加任务」54 px；中间列表独立滚动。
- 父任务使用 21 px 方形编号框，子任务使用 18 px 圆形勾选框。点击父任务的编号可切换完成状态；点击任务标题区域或箭头可展开详情。顶部进度表示已完成父任务数 / 全部父任务数。
- 窄栏只显示编号、标题和进度。没有子任务时隐藏进度，不显示 0/0。点击整行或箭头，在当前任务项内向下展开备注、子任务进度和子任务列表，后续任务自然向下排列；重复点击收起。没有备注或子任务时隐藏对应区域，不保留空白。箭头由 > 转为 ∨。不创建独立详情面板，不改变侧栏宽度、窗口宽度和主专注布局。任务使用留白、浅分隔线与轻微 hover。
- 添加任务在侧栏底部打开局部创建区，使用短距离上移动画。默认收起详情，只显示名称、展开详情入口和取消 / 创建任务按钮。展开后显示描述与子任务，收起详情仍保留已输入的描述和子任务。
- 子任务按 Enter 添加，忽略空白，清空输入并保留焦点。最多 20 项，计数实时变化；删除一项后恢复输入容量。长列表在创建区内部滚动，底部按钮保持可见。
- 取消、关闭创建区或退出专注会丢弃尚未提交的草稿。父任务右键菜单为编辑任务名称、编辑备注、删除任务；子任务菜单为编辑子任务名称、删除子任务。编辑使用当前任务项内的隔离编辑区，保存时提交；取消或切换任务会丢弃编辑。名称 Enter 保存，备注支持换行及 Ctrl+Enter 保存，Esc 取消编辑或收起任务。删除项使用红色。
- 父任务完成时方框显示勾号；子任务保留圆形勾选框。已完成名称变灰并增加删除线；已完成父任务和子任务分别沉到底部。排序仅作用于显示，保留存储顺序，取消完成后恢复原始位置。

## 数据与持久化

沿用现有目标和任务的关联。数据库迁移至版本 9，初始化程序在升级现有数据库前沿用原有备份机制。

| 数据 | SQLite 字段 |
| --- | --- |
| 父任务 ID、所属目标 | `tasks.task_id`、`target_id` |
| 标题、描述 | `name`、新增 `description` |
| 完成状态、顺序 | `is_completed`、`sort_order` |
| 创建、更新、完成时间 | `created_utc`、`updated_utc`、`completed_utc` |
| 子任务 | 新增 `subtasks` 表：`id`、`task_id`、`title`、`is_completed`、`sort_order`、`created_utc`、`updated_utc` |

`subtasks.task_id` 外键关联父任务，并使用 `ON DELETE CASCADE`。任务 ID 和子任务 ID 稳定，编辑保留创建时间。展开状态仅保留于界面。

描述与子任务加入 Core 模型和 IPC DTO，通过现有 Desktop → Service → SQLite 保存链路传递。任务及子任务的新增、读取、更新、删除使用目标和任务的原子保存事务；删除父任务或目标时级联清理子任务。SQLite 保存前校验子任务归属、稳定 ID、非空标题和 20 项上限。

创建和编辑使用隔离的草稿，确认后一次提交。勾选已有子任务立即触发保存；父任务完成逻辑继续接入原专注记录。连续保存按顺序执行，旧服务快照不会覆盖等待保存的新编辑；加载服务快照不会再次触发回写。

## 验证

相关测试覆盖：无子任务隐藏进度、项内展开及后续任务位移、展开收起不改变窗口布局、空详情不留占位、父子任务右键菜单及编辑提交、完成态删除线与完成项置底、取消完成恢复顺序、窗口展开与恢复、任务整行与箭头交互、回车连续输入与焦点、20 项上限、取消草稿、编辑保留 ID、完成进度、创建区长列表布局、SQLite 重启恢复与级联删除、旧数据库迁移，以及 Service IPC 数据往返。

渲染预览位于 `artifacts/task-drawer-qa/`：窄栏列表、项内详情、项内备注编辑、创建详情展开 / 收起、完成态，以及父 / 子任务菜单。
