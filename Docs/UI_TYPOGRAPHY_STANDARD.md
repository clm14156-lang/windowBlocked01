# UI 字体规范

适用于页面、弹窗、列表、统计与图表。所有字号使用 WPF DIP；主题切换保持文字层级一致，颜色使用对应主题资源。

## 1. 字体

| 角色 | 字体资源 | 字体 |
| --- | --- | --- |
| 中文、界面文字及中文单位 | `FontFamilyPrimary` | Microsoft YaHei UI |
| 英文、时间范围、图表刻度 | `FontFamilyEnglish` | Segoe UI Variable Text |
| 统计数字、倒计时 | `FontFamilyNumeric` | Segoe UI Variable Display |

图标使用独立图标资源，不混入正文字体。

## 2. 字号与字重

| 角色 | 字号 | 字重 |
| --- | ---: | ---: |
| 页面、弹窗主标题 | 18 | 600 |
| 模块标题 | 15 | 600 |
| 正文、列表、菜单、输入文字 | 13 | 400 |
| 统计标签 | 13 | 400 |
| 时间范围、普通操作按钮 | 13 | 500 |
| 主操作按钮 | 13 | 600 |
| 辅助说明、数字单位 | 12 | 400 |
| 图表坐标、紧凑刻度 | 11 | 400 |
| 统计主数字 | 28 | 600 |

400 用于常规阅读，500 用于操作与适度强调，600 用于标题及核心数字。700 仅用于明确规定的专用组件。

专用展示层级：

| 场景 | 字号 / 字重 |
| --- | --- |
| 专注主计时、完成结果大计时 | 100 / 400 |
| 完成结果：主标题、提示文案 | 18 / 600、13 / 400 |
| 完成结果：双列标签、数值、单位 | 13 / 400、20 / 600、12 / 400 |
| 结束专注确认：标题、底部“结束专注” | 26 / 700、14 / 400，保持固定 |
| 结束专注确认：“继续专注” | 14 / 500 |

## 3. 文字颜色

| 语义 | 浅色主题 | 用途 |
| --- | --- | --- |
| 主文字 | `#18212F` | 标题、核心数字 |
| 正文 | `#374151` | 列表、目标名称、有效日期 |
| 次级文字 | `#667085` | 标签、单位、说明 |
| 弱说明 | `#7C8798` | 辅助信息、刻度 |
| 弱化状态 | `#98A2B3` | 无数据日期、禁用文字 |
| 反白文字 | `#FFFFFF` | 主按钮、选中日期 |

深色主题使用对应语义色，保证明暗层级与可读性。浅色页面的普通文字使用中性色，蓝色不作为默认正文色。

## 4. 组件约定

- **按钮**：登录、注册、自定义时间“添加”、日历与目标详情的 VIP 开通按钮统一为 13 / 600、白字，默认底色 `#FF9035`；普通操作按钮保持 13 / 500。按钮内文字继承按钮样式。
- **数值**：数字与中文单位分开设置字号、字重，并保持基线对齐；时间字段需要对齐时使用等宽数字。
- **列表与菜单**：正文使用 13 / 400；需要强调的选中项使用 500。月份菜单保持常规字重，以浅灰底和勾选表示选中。
- **总览图表悬浮卡片**：白底、`#E3E7EE` 描边及轻阴影；日期和说明用 13 / 400、`#8A919F`，占比用 12 / 400、同一次级色。目标名称为 14 / 500，周标题为 14 / 600，均用 `#18212F`；核心时长整段使用 `FontFamilyPrimary`、13 / 600、`#18212F`，数字与中文单位保持相同字号、字重及颜色，仅显示小时和分钟，不足一分钟显示“不足1分钟”。
- **日历时段汇总时长**：数字、小时、分钟及“不足”前缀统一使用 `FontFamilyPrimary`、13 / 500、次级文字色 `#667085`，基线对齐，数字与单位间隔 3 DIP、小时与分钟分组间隔 6 DIP，整体右对齐。
- **时间轴休息项**：单行显示“休息 + 时长”，统一 12 / 400、次级文字色；图标与首行文字垂直居中。

## 5. 日历热度文字

热度仅作用于日期下方的专注时长，根据当天实际累计时长匹配；日期数字不使用热度色。

| 当天专注时长 | 时长文字颜色 |
| --- | --- |
| 0 ＜ 时长 ＜ 1 小时 | `#EBB28C` |
| 1 ≤ 时长 ＜ 2 小时 | `#E69A6C` |
| 2 ≤ 时长 ＜ 4 小时 | `#E37F4C` |
| 4 ≤ 时长 ＜ 8 小时 | `#D9642D` |
| 时长 ≥ 8 小时 | `#BF481F` |

- 有数据日期使用正文色，无数据日期使用 `#98A2B3`，且不显示时长。
- 选中日期保持橙色背景与白色文字，热度色不覆盖选中态，不添加黑色描边。
- 热度规则不得改变普通、悬停或选中状态的背景。

## 6. 使用规则

- 优先复用 `Typography.xaml`、`StatisticsTypography.xaml`、`CalendarTypography.xaml` 与 `PrimaryActionButtons.xaml` 的语义样式和主题资源。
- 专用组件遵循其明确规定的层级；用户指定保留的字号、字重优先，不因通用规范批量覆盖。
- 同类信息保持一致，避免临时新增字号、字重或颜色；不通过透明度叠加、描边模拟文字层级。
- 多行正文建议行高 20，辅助说明 18；单行文字垂直居中，长名称使用省略与完整提示，不随意缩小字号。
