# UI_TYPOGRAPHY_STANDARD.md

## 1. 目的

本文件用于统一整个 Windows 桌面软件的字体规范。

AI / Codex 在开发、还原、修改任何 UI 页面之前，必须先读取并遵守本文件。

**字体规范优先级高于参考图。**

参考图可以用于判断文字层级、位置、间距和视觉比例，但不得为了叠图完全重合而随意创建新的字号、字重或文字颜色。

---

## 2. 全局字体

### Windows 推荐字体

- 英文 / 数字：`Segoe UI Variable`
- 中文：优先使用系统中文字体回退，如 `Microsoft YaHei UI`
- 不强制使用 SF Pro、PingFang SC 等 Apple 专用字体

WPF 中优先使用：

```xml
FontFamily="Segoe UI Variable"
```

如果系统不支持，则回退为：

```xml
FontFamily="Segoe UI"
```

---

## 3. 固定字号体系

整个项目正常情况下只允许使用以下字号：

| 类型 | FontSize | FontWeight | 用途 |
|---|---:|---|---|
| PageTitle | 20 | SemiBold / 600 | 页面主标题 |
| DialogTitle | 17 | SemiBold / 600 | 弹窗主标题 |
| SectionTitle | 15 | Medium / 500 | 区域标题、模块标题 |
| Body | 13 | Regular / 400 | 正文、列表、菜单 |
| Button | 13 | Medium / 500 | 按钮文字 |
| Secondary | 12 | Regular / 400 | 次级说明、辅助信息 |

### 强制规则

- 正常 UI 文字不得小于 `12`
- 禁止随意使用 `11、14、16、18、19px`
- 禁止为了匹配参考图临时创建新字号
- 如果现有字号不合适，先判断文字层级是否定义错误，不要直接新增字号
- 新字号必须先修改本规范，再在项目中使用

---

## 4. 字重规范

全项目主要只使用三档字重：

```text
Regular   = 400
Medium    = 500
SemiBold  = 600
```

使用规则：

- 普通正文：400
- 按钮 / 区域标题：500
- 页面标题 / 弹窗标题：600

### 禁止

- 普通正文使用 Bold
- 同一级标题在不同页面使用不同字重
- 无明确原因使用 700 / Bold
- 为了“看起来更像参考图”单独修改字重

---

## 5. 文字颜色

推荐统一使用：

```text
PrimaryText   = #1D1D1F
SecondaryText = #6E6E73
WeakText      = #8E8E93
DisabledText  = #AEAEB2
WhiteText     = #FFFFFF
```

### 使用规则

- 页面标题 / 主要正文：`#1D1D1F`
- 次级说明：`#6E6E73`
- 时间、状态、弱提示：`#8E8E93`
- 禁用文字：`#AEAEB2`
- 深色主按钮文字：`#FFFFFF`

### 禁止

- 普通文字直接使用纯黑 `#000000`
- 每个页面自行定义不同的灰色
- 同一级文字在不同页面使用不同颜色

## 7. AI / Codex 开发约束

每次开发 UI 时必须遵守：

1. 先读取本文件，再修改 UI。
2. 不允许根据单张参考图自由决定字体大小。
3. 参考图只用于判断文字属于哪一级 Typography。
4. 字体必须优先从本文件已有标准中选择。
5. 不允许为了叠图对齐，把 15 改成 14、16 等临时字号。
6. 相同层级的文字，在所有页面必须保持相同字号、字重和颜色。
7. 修改某个页面时，不得破坏其他页面已有的全局字体规范。
8. 如果发现现有页面字体不符合规范，应优先统一到本规范。
9. 如果设计确实需要新增字体层级，必须先说明原因，不得直接创建。
10. UI 还原完成后，除检查参考图差异外，还必须检查与其他页面的字体一致性。

---

## 8. 优先级

发生冲突时按照以下优先级执行：

```text
全局 Typography 规范
    ↓
组件统一规范
    ↓
当前页面设计
    ↓
参考图像素级还原
```

也就是说：

**宁可与参考图字体大小存在轻微差异，也不要破坏整个软件的字体一致性。**

---

## 9. 核心原则

> 字体不是逐页面设计，而是整个软件共享的一套系统。

> 参考图决定布局和视觉关系，全局 Typography 决定字号、字重和文字颜色。

> 所有页面只能从统一字体层级中选择，不允许自由发挥。
