# 专注页面问候文案

用户配置文件：`%LOCALAPPDATA%\FocusApp\Config\FocusGreetings.txt`。

应用首次创建专注 ViewModel 时，会在文件不存在的情况下创建默认配置；后续启动和进入专注页面不会覆盖已有文件。删除文件后会重新生成默认配置。配置目录无法写入、文件无法读取或 UTF-8 格式无效时，应用使用内置默认文案。

用记事本打开该文件，按 `[早上好]`、`[下午好]`、`[晚上好]`、`[夜深了]` 四个分组编辑，每行一句，保存为 UTF-8。可以添加、删除或替换句子，空行自动忽略，条数没有固定限制。缺失或空白分组使用该阶段的默认文案；未知或损坏的分组标题及其内容会被忽略，其他有效分组仍然可用。重复的文案只参与一次抽取。

保存后，下次真正进入专注页面时读取最新文件，无需重新编译或重启。当前页面的文案保持稳定；跨时间阶段时，标题、图标和副文案一起更新，副文案只抽取一次。同一阶段有多句不同文案时，避免与上一次抽取结果重复。最小化、恢复和悬浮窗口切换不会触发重新读取或抽取。

进入专注时的文件读取与解析在后台线程执行，完成后在原调用上下文发布文案。过渡动画在首次布局和文案就绪后开始，避免动画期间同步读取磁盘；等待读取时保留旧页截图，问候区保留原布局占位但暂不显示旧文案。取消或开始新会话后，旧读取结果不会覆盖新会话文案。读取失败仍使用内置默认文案，主题选择和专注计时不等待文件读取。

阶段规则沿用原实现：05:00–11:59 早上好，12:00–17:59 下午好，18:00–22:59 晚上好，其余时间夜深了。

项目默认模板位于 `src/FocusApp.Desktop/Config/FocusGreetings.txt`，作为嵌入资源随桌面程序发布。安装版只向用户配置目录写入，不依赖安装目录写权限。默认文案可完整显示；超长自定义文案沿用页面已有的单行省略处理，保持原来的位置、字体、计时器及其他元素布局。
