# 专注页面自然天气

## 实现边界

复用 `focusPage` 中浅色三张（`shuye_001.png`、`shuye_002.png`、`shuye_003.png`）、暗色两张（`dark_yezi01.png`、`dark_yezi02.png`）透明叶子 PNG，保持背景、人物、阴影、倒计时、字体、布局、TodoList 和结束流程不变。
原有 `FocusLeafLayer` 名称及 `FocusLeaves` XAML 名称保留，内部改为单个 `FrameworkElement.OnRender` 天气绘制层。
移除不再使用的 `FocusLeafMotion` Storyboard 实现，没有新增第三方依赖或设置入口。

## 天气生命周期

`FocusWeatherController` 只负责状态、持续时间、冷却和风力；`FocusWeatherParticles` 管理固定容量的粒子槽位。
一个低频 DispatcherTimer 到期后停止自身，再预约状态结束或首次降雨准备节点中的较早者。
等待几十秒后的天气变化不依赖逐帧循环。

每次专注从 Calm 开始。转移约束和权重为：

| 当前状态 | 下一状态 |
| --- | --- |
| Calm | 首次有效降雨前 28% Rain；完成后冷却结束时 23% Rain，其余 Breeze |
| Breeze | 35% Calm、25% Windy、40% Breeze |
| Windy | Calm |
| Rain | Clearing，同时开始随机 180–360 秒降雨冷却 |
| Clearing | Calm |

微风可能包含几个独立的随机风段，也可能直接回归平静或增强为起风。起风后经过平静，十片叶子有时间自然结束，
不会把起风的残留叶子直接带入最多五片的微风状态。Rain 只能从 Calm 进入，Clearing 只能紧随 Rain。
正常完成且有足够可见时间的会话保证至少一次小雨；其他天气仍随机，不要求覆盖所有状态。

首次降雨保底时间按本次总时长选择：5 分钟为随机 90–180 秒，10 分钟及以上为随机 180–300 秒，
5–10 分钟连续插值。自然抽选提前下雨时沿用完整雨段；稳定雨量达到约 90% 后实际更新累计十秒才确认首次降雨完成。
确认后取消首次保底，后续恢复普通概率及 180–360 秒冷却；首次雨段未有效显示时保底仍待完成。
未下雨的情况下，保底前二十秒主动进入 Calm，停止新叶子生成，让最长十八秒的旧叶子自然运动退场，然后进入 Rain。
这个首次准备段可以短于普通 Calm 范围，不改变粒子寿命、速度、淡出或风力插值。
准备和降雨都复用已有状态定时器，不新增 Timer，也不依靠逐帧轮询等待保底。

Calm 不生成任何新叶子或雨滴；已有叶子继续飘落和淡出，雨滴继续下落，已经产生的涟漪自然消失。
残留雨滴抵达有效地面后仍完成对应的落地涟漪，最后一个涟漪退场后停止逐帧更新。
40%–50% 是长期完全静止时间的统计目标，以 Calm 且无任何活动粒子为准；单次短会话允许偏离。
运行时不为追赶该比例插入或打断天气，首次降雨保底是独立的会话要求。

## 根据专注总时长调整节奏

XAML 将已有 `TotalFocusSeconds` 和 `RemainingFocusSeconds` 单向绑定到天气层，控制器按分钟连续插值：

| 状态 | ≤5 分钟 | 25 分钟 | ≥60 分钟 |
| --- | --- | --- | --- |
| Calm | 30–60 秒 | 40–80 秒 | 55–110 秒 |
| Breeze | 15–25 秒 | 20–40 秒 | 30–60 秒 |
| Windy | 10–20 秒 | 10–25 秒 | 15–30 秒 |
| Rain | 25–40 秒 | 30–60 秒 | 45–90 秒 |
| Clearing | 5–8 秒 | 5–10 秒 | 5–10 秒 |

5–25 分钟和 25–60 分钟分别在相邻参数之间线性插值，状态时长在所得范围内随机选取。
开场平静没有残留粒子退场，因此只在普通 Calm 区间的较短 70% 内随机取值：5/25/60 分钟分别为 30–51、40–68、55–93.5 秒。
后续普通平静段使用表中完整区间，避免首次降雨保底加入后，反复进行五分钟短会话的平均静止占比超过上限。
只调整状态节奏，粒子速度、寿命和风力平滑时间不随专注时长整体缩放。
中途总时长变化时保留当前状态的进度和随机分位，重新预约同一个状态定时器。
尚未完成首次降雨时重新计算首次截止时间；已开始准备则不向后推迟，也不取消二十秒的退场时间。
恢复显示时依据剩余专注时间提前安排尚未完成的首次降雨，并为雨段、雨停及退场预留时间。
隐藏、最小化期间不生成雨滴或累计可见降雨；提前结束或隐藏至剩余时间不足时，不延长专注来等待天气。
现有会话没有独立暂停命令；天气可见时钟与倒计时独立，结束专注直接停止天气，不等待其播放完毕。

## 风、落叶、小雨与涟漪

- 一个共享 Random 同时供状态及粒子系统使用，每片叶子从左、右或顶部随机进入。
- 叶子尺寸 20–34 DIP，预设寿命 8–18 秒；个体横向速度、24–52 DIP/s 下落速度、正弦摆动、轻微倾斜、透明度均独立随机。
  前约 1.2 秒淡入，最后约 2 秒淡出，离开边界可以提前回收。微风最多五片，起风最多十片，生成间隔随机错开。
  上限不代表始终填满；生成间隔、运动参数和随机寿命沿用现有实现。
- 叶子完整图片外接正方形的半对角线作为保守边界，覆盖任意旋转和图片宽高比。
  下缘距离分隔线 50 DIP 时开始边界淡出，透明度系数为 `(剩余距离 / 50)^3`，即反向 cubic EaseOut。
  与现有入场/寿命透明度相乘，淡出不可恢复；位置、摆动、旋转继续更新，边界透明度归零后才回收。
- 控制器保留当前风速、目标风速、过渡起点及进度；用 smoothstep 在随机 3–6 秒内平滑变化。
  每片叶子的水平速度为个体漂移加全局风速，没有风场网格、碰撞或物理引擎。
- 雨滴使用宽 1 DIP、长 14–22 DIP、33% 透明度的浅蓝线段，速度 190–300 DIP/s，位置及生成时间随机，允许少量风偏移。
  稳定雨量下随机生成间隔为 0.045–0.08 秒，正常帧保留间隔余量，使 30 FPS 下实际雨量约为此前的两倍。
  最多 64 滴，每帧最多生成一滴；超过 50 ms 的慢帧丢弃间隔余量，不进行整批生成或卡顿后的补发。
  Rain 的生成强度在随机 5–10 秒内平滑增加；Clearing 在自己的 5–10 秒范围内逐渐降为零，现有雨滴不会被突然删除。
- 每个抵达有效地表的雨滴回收时产生一圈扁椭圆，雨停后的残留雨滴也完成落地反馈。水平半径从 2.5 DIP 以 cubic EaseOut 扩展到独立随机的 11–12 DIP，
  垂直半径为水平的 31%，画笔透明度保持 25%，随 smoothstep 平滑淡出，随机 0.7–1.1 秒后回收。
  雨滴出生前按最大椭圆范围加 1 DIP 的描边/抗锯齿余量确定可用横向范围；随机落点在地面条带内预留完整扩散空间。
  横向范围只在视口变化时计算，保留风偏移并限制在该范围，雨滴抵达的坐标就是涟漪中心，不在落地时移动涟漪或截断圆圈。
  固定预留 96 个涟漪槽位，覆盖 64 滴集中落地及此前 1.1 秒内的落地反馈；上限不代表始终显示这么多圈。
  不增加描边圈数、水花或绘制控件。地表不可见或容不下完整涟漪时不伪造地面。

## 裁剪和主题

`FocusFlowView` 把已有背景、分隔线和页脚传给天气层，仅用于读取布局。
分隔线实际顶部为天气裁剪下边界，强制模式隐藏分隔线时退回页脚顶部；不根据截图硬编码屏幕坐标。
绘制层在背景之上、现有内容之下，命中测试关闭。落叶、雨滴和涟漪只使用页面/分隔线外边界裁剪，
不扣除人物、倒计时、任务文字和问候的矩形区域；角色自然遮挡其背后的天气，而不会产生矩形缺口。
天气层不再构建扣除 UI 矩形的几何。

地面是两张现有背景图的前景丘陵内部狭窄区域，使用图片归一化坐标和实际 `UniformToFill` 缩放/居中裁剪映射到当前容器。
分隔线不参与落地判定；涟漪最多到分隔线以上 10 DIP，避免扩散半径接触按钮区。
图片尺寸或窗口尺寸变化后重建冻结的裁剪几何、清除旧尺寸粒子，不重启天气状态。
地表的图内比例是对现有美术的近似，未来更换背景时需要重新核对。

两套主题继续提供原有 `FocusSceneLeaves`，新增各自浅蓝色 `FocusWeatherBrush`。
叶子预加载、按 64 像素宽解码并冻结，主题切换直接使用新共享素材和画笔，保留状态及个体运动进度。

## CPU、GPU、内存和生命周期

- 所有天气只用一个目标 30 FPS 的更新定时器和一个绘制层，无逐粒子控件、Storyboard 或 Timer。
- 位移和旋转使用 Stopwatch 的实际 elapsed time；每次粒子更新将 deltaTime 限制在 0–0.1 秒，不补算停顿期间的轨迹或生成积压。
- 完全 Calm 且粒子为空时，最后一次空绘制清除画面后停止更新定时器。只剩下一次状态切换预约，没有天气逐帧重绘。
  本实现从未订阅 `CompositionTarget.Rendering`，所以不存在需要留在平静期的订阅。
- 固定槽位上限：10 片叶子、64 条雨滴、96 个涟漪。只复用数组和数值结构，不引入复杂对象池。
- 复用十个叶子变换、冻结雨滴/涟漪 Pen 和裁剪几何；每帧不重新解码图片，不创建粒子对象。
- 最小化、隐藏、卸载时停止两个天气定时器和可见时钟，清除残留粒子，隐藏期间也跳过天气布局计算。
  恢复时保留状态、剩余状态时间及冷却，不补绘、不追赶生成。
- 关闭/卸载解除宿主窗口事件，停止定时器；再次加载复用同一调度器，真正结束会话后下次从 Calm 重新开始。
- 不修改专注计时器或原有完成逻辑。目标帧率是调度参数，并非实际测量的帧率保证。
  静止时间目标降低后，总动画工作时间会增加；不能据此宣称实际 CPU/GPU 开销不变。
