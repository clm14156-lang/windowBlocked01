# UI 设计规范

> 版本：V1.0
> 适用：FocusApp.Desktop、FocusApp.Agent 的 WPF 界面
> 特殊页面如需违反规范，必须在对应 UI 文档中说明。

## 1. 整体风格

* 默认窗口：800 × 710 DIP。
* 风格：简洁、克制、留白充足、层级清晰。
* 以白色、浅灰为主，主题色只用于关键操作和选中状态。
* 每个页面最多一个最高视觉优先级操作。
* 禁止厚重阴影、复杂渐变、发光和无意义装饰。

## 2. 布局与间距

* 左侧导航：80。
* 顶部标题栏：48。
* 主内容左右边距：40。
* 主内容顶部边距：28。
* 内容最大宽度：680。
* 模块间距：32～48。
* 模块内部：8～16。

优先使用：

`4 / 8 / 12 / 16 / 24 / 32 / 40 / 48 / 64`

禁止随意使用零散间距。

## 3. 字体

字体：

* 中文：Microsoft YaHei UI
* 英文：Segoe UI Variable Text
* 数字：Segoe UI Variable Display

字号：

* 倒计时：44
* 核心操作：24
* 页面标题：20
* 模块标题：16
* 卡片标题：15
* 正文 / 按钮：14
* 次要文字：12

规则：

* 默认字重 400，标题和按钮 600。
* 最小字号 12。
* 单页面最多使用 4 种字号。

## 4. 颜色

页面只能使用语义颜色资源，不直接写死颜色。

核心资源：

* `BackgroundPrimary`
* `BackgroundSecondary`
* `SurfacePrimary`
* `TextPrimary`
* `TextSecondary`
* `BorderPrimary`
* `AccentPrimary`
* `AccentTint`
* `Success`
* `Warning`
* `Danger`

默认浅色参考：

* 背景：`#F7F7F8`
* 卡片：`#FFFFFF`
* 主文字：`#1D1D1F`
* 次文字：`#6E6E73`
* 边框：`#E5E5EA`
* 主题色：`#FF7A00`

高饱和颜色只用于关键按钮、选中状态和重要提示。

## 5. 圆角、阴影与控件

圆角：

* 标签：8
* 输入框 / 菜单 / 导航：12
* 卡片 / 弹窗：16
* 胶囊按钮：高度一半

控件：

* 主按钮：44～48 高
* 普通按钮：40～44 高
* 输入框：44 高
* 导航点击区：40 × 40
* 普通图标：16～20
* 导航图标：20～22
* 最小点击区域：36 × 36

阴影：

* 普通按钮无阴影。
* 卡片优先使用浅边框。
* 必要时使用轻微阴影。
* 禁止明显发光和厚重阴影。

## 6. 按钮与卡片

### 按钮

主按钮：

* 主题色背景。
* 白色文字。
* 一个页面最多一个。

次要按钮：

* 浅灰、描边或透明背景。
* 不得抢主按钮视觉优先级。

危险操作：

* 仅删除、退出、清除数据等使用红色。

### 卡片

* 圆角 16。
* 内边距 20～24。
* 卡片间距 16。
* 只展示核心信息。
* 避免卡片嵌套卡片。
* 能使用留白或分割线时，不额外创建卡片。

## 7. 交互

所有可交互控件至少支持：

* Default
* Hover
* Pressed
* Selected
* Focused
* Disabled
* Loading

动效保持轻量：

* Hover：120ms
* Pressed：80ms
* 展开：180ms
* 弹窗：200ms
* 页面切换：220ms

统一使用 EaseOut，禁止弹跳、闪烁和大幅缩放。

## 8. 导航

* 左侧导航固定宽度 80。
* 图标统一使用线性风格。
* 当前页面：浅主题背景 + 主题色图标。
* 未选中：次要文字颜色。
* 用户 / 会员入口放导航底部。

## 9. 首页视觉优先级

从高到低：

1. 开始专注
2. 专注时间
3. 专注目标
4. 当前屏蔽信息
5. 导航、主题、会员入口

“开始专注”是首页唯一的大面积主题色元素。

## 10. 主题与多语言

* 所有颜色通过 `DynamicResource` 引用。
* 页面不得根据主题 ID 编写业务判断。
* 新主题不得修改业务页面代码。
* 所有页面和悬浮窗口自动继承当前主题。
* 所有文字使用资源键，不直接写死中文。
* 英文文本预留至少 30% 扩展空间。
* 图标和文字不得合并为图片。

主题包结构、VIP主题、皮肤资源等详细规则统一参考 `THEME_SYSTEM.md`。

## 11. WPF 基础要求

* 使用 MVVM。
* 使用 `ResourceDictionary`、`Style`、`ControlTemplate` 统一界面。
* 使用 DIP，不使用物理像素。
* 支持 Windows DPI 缩放。
* 开启 `UseLayoutRounding` 和 `SnapsToDevicePixels`。
* 禁止页面重复定义已有通用样式。

## 12. 禁止事项

禁止：

* 页面写死颜色。
* 随意使用字号、间距和圆角。
* 一个页面出现多个主操作。
* 大面积渐变、发光、厚重阴影。
* 不同页面使用不同控件规则。
* 为填满页面增加无意义内容。
* UI 或主题修改影响专注、屏蔽、会员和其他业务逻辑。
