# 再次专注确认弹窗与 Todolist 配色

`FocusFlowView` 的再次专注弹窗固定为 330 × 180 DIP，圆角 20，移除原来的问号图标。标题改为“再次专注？”，与“结束专注？”共用 `FocusConfirmationTitle`，沿用现有的 26 DIP/Bold。两种模式的背景与边框均直接使用结束专注弹窗的 `FocusEndDialogBackground`、`FocusEndDialogBorder`；暗色背景为同一深蓝渐变资源。

正文居中分为两行：“你刚刚专注了 [本轮实际时长]，”与“要再继续一轮吗？”。时长继续绑定已有 `CompletedDurationDisplay`，以橙色和 SemiBold 突出；正文使用现有 Body 字号，长时长仅由 Viewbox 缩小以避免溢出。内容边距为左/右 24、上 22、下 18，左右按钮等宽，间距 12，高度 40，圆角 20。取消按钮为主题对应的透明描边样式，确认按钮复用结束专注按钮的橙色渐变。右上角新增关闭按钮，复用取消命令。

取消、关闭和确认仍使用原有 `CancelFocusAgainCommand`、`FocusAgainCommand`，确认后仍按原设置时长重启，不改变专注计时、历史记录、任务状态或结束页主题保留逻辑。

暗色 Todolist 的激活创建按钮改为参考图中的较深蓝色 `#405982`，浅色创建按钮仍用现有橙色。两种模式的“已推进”进度条使用单独的 `FocusTaskProgressFill` 橙色渐变（`#FFA12D` 至 `#FF8816`），保持原有 6 DIP 高度和圆角。这个资源与子任务勾选的 `FocusTaskProgressAccent` 分开，进度值、底轨、勾选颜色及禁用状态均沿用原实现。

验证包含两种模式的原生 WPF 渲染、固定尺寸、标题与结束弹窗一致、两行正文、按钮及关闭命令、原时长重启、实际进度比例、创建按钮激活/禁用状态，以及切换主题保留草稿和进度。

按钮文案使用显式内容模板，文字颜色、字体、字号和字重直接绑定所属 Button，避免应用级隐式 TextBlock 样式的 `TextPrimary` 覆盖继承值。原先将公共资源仅加载到 View 的截图不能复现这个应用级样式覆盖；回归验证补充了按钮真实文字控件的样式冲突检查，并在独立 WPF 应用进程中按 App.xaml 的资源层级复现、导出修复前后两种主题效果。
