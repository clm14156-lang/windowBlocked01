# 目标详情：概览、日期记录与时间筛选

目标页保留左侧 190 DIP 的当前/归档目标列表、创建目标及既有目标操作，右侧保留上下两张独立白色卡片。概览卡片显示目标名称、描述，以及横向等宽的累计投入、完成任务数、专注天数三个无卡片指标，通过两根 1 DIP 浅灰竖线分隔；标签和数字继续使用统计页统一字体规范，保留宽度不足时等比缩小。分别使用橙色时钟、绿色完成、蓝色日历图标。累计投入和完成任务数标题右侧保留浅灰色细箭头，继续打开既有弹窗，专注天数仅展示数据。顶部三个指标与下方记录共同使用已选时间范围，切换时立即刷新。

三个指标直接从 `GoalFocusHistoryViewModel.Days` 内的真实专注记录计算：累计投入汇总保存的 `FocusDuration` 后取整到分钟；完成任务数汇总符合现有历史完成判定的任务快照；专注天数统计筛选后的日期分组数量。零专注时长和其他目标的记录不参与分组。历史记录与顶部统计统一按开始日期归属，跨午夜记录完整保留在开始日期下，避免顶部指标与记录列表口径不一致；当日汇总也使用保存的专注时长，排除暂停时间。

记录区单独成卡，标题和时间筛选固定，只有列表内部滚动。日期与开始时间仍倒序排列，日期行改为 40 DIP 高的纯白列表，不使用浅灰卡片或圆角；每行底部使用 1 DIP 浅灰横线，当年记录只显示月日，跨年记录保留年份，后接星期、当天总专注时长及展开箭头；完整日期仍用于无障碍名称。日期文案使用现有本地时间提供器，不读取硬编码年份。日期展开后，每次专注第一行展示时间范围和右侧持续时长，下方直接展示该次记录的任务列表，不再需要逐条点击任务数量胶囊。橙色小圆点与淡橙色细线连接同一天的专注记录，不再插入旧版间隔行或连续分组留白。

任务仍使用既有只读历史快照：方形橙色完成标记、灰色删除线、备注悬浮提示及缩进的子任务关系线。历史完成判定、任务成员及备注不受后来编辑实时任务的影响。没有任务的专注记录只展示时间和时长。日期默认折叠，保留原有展开行为；同一目标的数据刷新或时间筛选保留已有日期展开状态，切换目标后重置。

左侧目标行不再显示 hover 更多按钮，名称宽度不随 hover 或菜单开关改变。唯一的“···”固定在右侧详情右上角，操作绑定当前选中目标，保留编辑、归档、恢复、删除及各自显示条件；VIP 锁定详情同样可以操作目标。切换目标、离开目标页或执行菜单操作时关闭菜单。

时间筛选默认“全部时间”，第一层菜单包含全部时间、近7天、近30天、按月查看。第一层菜单收窄为与筛选按钮一致的 130 DIP，去掉选项前的重复日历图标；浅灰选中态、右侧勾选和中性灰 hover，保留圆角、轻阴影和向下弹出。近7天和近30天按本地自然日计算，包含今天以及前6/29天，排除未来日期。历史记录继续按开始日期归属；跨午夜的单次记录完整保留在开始日期下，不拆成两条，也不因月份边界重复出现。

“按月查看”先关闭第一层菜单，再直接打开宽 130 DIP 的纵向月份菜单。仅列出当前目标存在有效记录的月份，按完整年月倒序排列，不受已选近7天或近30天影响；删除年份切换与12个月网格。每行高 30 DIP，选中项使用浅灰背景和右侧灰色勾选，不使用橙色。内部最多显示 240 DIP，根据窗口可用空间调整高度与弹出方向，超出时内部滚动，再次打开时滚动到选中月份。点击月份后立即应用筛选、更新按钮年月并关闭菜单。两个浮层互斥，点击外部、Escape、切换目标或离开目标页时关闭，退出不改变已应用的筛选。没有可选月份时显示“暂无专注记录”；筛选无结果时显示记录空状态，三个顶部指标均为0。

筛选在已构建的日期分组上执行，切换范围不重新读取或复制历史任务快照。更新集中于目标详情和其记录视图，其他统计子页面、访问权限、目标创建和两个既有弹窗保留原有功能。

验证覆盖自然日边界、跨年和闰年月份、跨午夜归属、保存时长与暂停时间、筛选与展开状态恢复、三项指标联动以及记录更新后的月份列表；原生 WPF 检查两层菜单的实际点击、月份应用、长列表滚动、空状态、Escape、离页关闭，以及 800×710 和 900×760 布局。通过真实主窗口离屏渲染检查记录、筛选菜单、月份选择和空状态。
