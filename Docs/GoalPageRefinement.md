# 目标详情：投入概括与专注记录

目标详情保留两张并排的概括卡片：累计投入、完成任务数。整张卡片均可点击，分别复用现有投入趋势弹窗和已完成任务弹窗；不再显示近 7 天投入卡片及原来的独立入口。累计时长沿用原有统计，任务数量绑定当前目标的 `GoalCompletedTasks.TotalCount`，为 0 时仍可打开空状态弹窗。

专注记录仍按日期和开始时间倒序分组。日期行只显示当天时长。展开日期后，每个时间段仅在存在历史父任务时显示 `N个任务` 胶囊，胶囊独立控制任务展开，首次显示默认折叠。子任务不重复计数。

时间段左侧使用橙色圆点。同一天相邻记录之间的间隔按较晚记录的真实开始时间减去较早记录的真实结束时间计算，与日历页共用 `FocusRecordTimelineRules`：达到 5 分钟才显示浅灰间隔圆点、细线和文字；不足 5 分钟（含首尾相接和重叠）省略整个间隔行，用橙色线段保持相邻记录的连续分组。阈值使用完整时间精度判断，不先取整分钟，不跨日期连接。连续橙线随任务展开高度伸展；无相邻短间隔时保留原来的任务详情橙线。无任务记录仍不显示胶囊，但参与短间隔的连续时间轴。

时间段行上下边距各 2，标题占位高 24；仅在相邻短间隔记录之间增加 8 DIP 留白，并用橙线贯穿新增留白。橙线与上下橙色圆点边缘各留 2 DIP 微小间隙，保持连续分组又避免线顶到圆点。移除时间段之间的横向分隔线，保留日期分组和任务内部的原有层级。灰色间隔行仍为 24 高，灰色竖线上下各留 2，圆点与文字同处一行居中；有灰色间隔信息的记录之间不增加留白。任务文字行和子任务行的留白、字体、颜色、勾选标记和胶囊交互保持不变。

历史父任务使用橙色方形勾选标记，子任务使用缩进、浅灰树状连接线和圆形勾选标记，完成文字使用灰色删除线。展示沿用原有历史快照、任务筛选和完成判定，标记只读，不触发完成或恢复任务的业务逻辑。任务备注仍可通过悬浮提示查看。

仅记录列表内部滚动，目标名称、投入概括和专注记录标题保持固定。修改集中在 `StatisticsPage.xaml`、`GoalFocusHistoryView.xaml` 和 `GoalFocusHistoryViewModel.cs`；左侧目标列表、日历、其他统计页面、访问权限与弹窗业务保持原样。

相关测试覆盖卡片实际点击和弹窗打开、零任务计数、日期时长文案、父任务计数、真实间隔、独立折叠、无任务圆点、历史快照及子任务样式，并通过原生 WPF 渲染验证布局。
