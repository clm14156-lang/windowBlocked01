# 结束专注确认弹窗

弹窗保持现有 `FocusFlowView` 内居中的覆盖层结构，尺寸改为 330 × 300 个 WPF 逻辑像素，圆角 20，内容边距为左/右 24、上 24、下 14。标题 26/Bold，说明 13/Normal，时长数字 44/SemiBold，单位 18/Medium，警告文字 11.5/Normal。时长继续由原有 ViewModel 提供，Viewbox 仅在长时间数字需要时缩小，避免溢出。

主题使用现有 `FocusThemeScope` 与 `IsDarkFocusTheme`，新增的 `FocusEnd*` 主题资源仅服务此弹窗。深色为深蓝渐变背景、浅色标题和单位、透明警告区域；浅色为柔白背景、深色标题、浅橙色警告条。两版均使用橙色数字、橙色圆形警告标记和白色感叹号。

“继续专注”使用 42 高的橙色渐变按钮、16/SemiBold 白色文字、圆角 11 和轻微橙色阴影。按钮横向填满内容区域。“结束专注”为 14/Normal 的低优先级文字按钮。右上角叉号的原控件、28 × 28 尺寸、右/上 12 的位置、图形、样式和命令均保留原样。

不足五分钟仍提示“不足 5 分钟，结束后不会保存记录”；达到五分钟后仍展示原鼓励文案。状态区为居中的 240 × 34，阈值切换和主题切换不会移动标题、时间、按钮或关闭控件。继续、取消、提前结束及五分钟保存门槛均沿用原业务处理。

返回首页的结果事件仍执行导航；原 `ShowFocusResultToast(e)` 改为 `CloseFocusResultToast()`，不再自动显示专注完成 toast，也清理可能已经显示的结果提示及其计时器。专注结果、统计写入、历史记录和独立的通知测试入口保持原样。

相关验证覆盖原生 WPF 深浅主题渲染、运行时主题切换、五分钟阈值前后的布局、两个操作及叉号、自然完成和提前结束返回首页无 toast、记录及任务数量保留。
