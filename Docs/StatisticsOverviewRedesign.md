# 总览：周期统计与时间分布

总览以同一个 `StatisticsDashboardViewModel` 驱动三个统计卡片、专注时长柱状图及目标时间分布。生产入口继续使用 `StatisticsOverviewViewModel(useSampleData: false)`；总览没有静态演示数据或写死的时长、数量、占比。

“总专注时长”卡片沿用原有数字、单位字号、字重、颜色及基线对齐，数字与单位之间采用 4 DIP、小时与分钟两组之间采用 8 DIP 的固定间距，与本月统计的大数字排版一致。不足一小时时，小时部分连同对应间距收起；统计口径、时长文案和卡片尺寸保持原样。

## 周期和统计口径

- 右侧切换改为日／周／月，默认选中“日”。日视图展示所选自然周的 7 天，周一至周日，一天一根柱子；支持选择历史周。周视图展示所选 ISO 周年的每一周，全年 52 或 53 根柱子；月视图展示所选自然年的 12 个月。左侧点击日期区域弹出时间浮层，继续保留现有入口与布局。
- 图表标题随视图切换为“每日专注时长”“每周专注时长”“每月专注时长”。日视图展示日期及星期；今天使用橙色日期与“今天”标记。周视图按周一到周日汇总，保留全年所有周的位置，仅对拥挤的周刻度抽样显示，首末周仍有刻度；Hover 展示 ISO 周年、周编号和完整起止日期。周、月视图不把整周或整月称为今天。页面可见时每分钟检查日期，仅跨日时更新标记，不自动切换浏览周期。
- 日期浮层仅列出有正专注时长的周期，按新到旧排列。日视图列出 ISO 周年与周编号，周视图列出有数据的 ISO 周年，月视图列出有数据的自然年。ISO 周年按整周处理：例如 2026 年第 1 周从 2025-12-29 开始、第 53 周至 2027-01-03 结束。跨年周的时长、专注天数、完成任务与目标分布均使用同一个周年度区间；切换至月视图则按自然年重新统计。空时段、零时长不生成选项，不满一分钟的有效数据仍保留。选中项显示勾选，卡片、柱图和圆环同步刷新；没有历史数据时显示空提示，不插入演示选项。
- 复用 `FocusStatisticsCalculator.GetSlices`：使用已记录的实际专注时长，排除准备和暂停时长，并按当地午夜拆分跨日、跨月、跨年记录。所有统计使用同一个左闭右开日期区间。
- 总时长、各柱时长、各目标时长按原始 ticks 相加，先汇总再显示，避免把多个不足一分钟的记录提前截断。卡片、列表和 Hover 均显示分钟级时长，不显示秒；存在正时长但不足一分钟时显示“不足1分钟”，保留原始秒数和 ticks 参与统计。
- 专注天数统计周期内存在正专注时长的不同日期，跨午夜记录可计入两天。
- 完成任务沿用日历的历史记录口径：来自有效的已保存专注记录（至少 5 分钟）的任务成员与完成时间；有任务 ID 时在周期内去重。旧记录缺少 ID 时沿用已存储的任务成员数量，不用相同名称推断同一任务，也不混入无历史成员关系的当前任务。
- 时间分布按目标 ID 汇总，当前目标名称优先，已删除目标使用历史名称快照，空目标归入“自由专注”。百分比用原始时长相除，显示取整；小于 1% 时显示 `<1%`。
- 目标颜色在当前页面实例中保持稳定，不随周期切换改变。已归档/已删除目标的历史时间仍计入相应周期。
- Y 轴按当前数据自动选择合理刻度，空数据有有效刻度。全年月汇总不受旧版每天 24 小时刻度上限限制。

## 交互

- 日期浮层移除固定 218 DIP 宽度，按最长内容自适应，限定 128–200 DIP；行高 30 DIP、按钮左右边距 8 DIP、勾选列 18 DIP，日、周、月的浮层分别随内容收缩。日期区域 hover 使用浅灰圆角底，展开时箭头向上；浮层复用白底、浅灰描边和轻阴影的 PoptipChrome。点击外部、Escape、切换日/周/月、选中时间项、离页、卸载或窗口尺寸变化后关闭。
- Hover 环形扇区或列表行会激活同一目标，联动列表浅灰底、扇区约 2.2% 放大/4 DIP 外移和柔和阴影。
- 两个入口共用 PopTip，显示目标名称、专注时长和占比。柱状图共用相同的 PopTip 外观，仅在有正专注时长的日期／月份区域显示日期和分钟级时长，零时长、无记录或未产生数据的桶不命中；移入空数据区域立即关闭共享浮层，不显示“0分钟”。不足一分钟但确有时长的记录显示“不足1分钟”，环形图已锁定时也不会在空图表区域恢复提示。
- 总览 PopTip 使用白底、浅灰描边、圆角与轻阴影。时长整段（数字、小时、分钟）统一为微软雅黑 UI 13 / 600、`#18212F`，避免中文单位与数字因字体回退呈现不同粗细。目标名称为 14 / 500，日期为次级灰 13 / 400，占比独立放在底部 12 / 400；周提示以 14 / 600 显示周年与周编号，下方另列灰色 `MM.dd - MM.dd`，跨年范围保留两端年份。保留真实时长精度与现有联动、定位和关闭逻辑。
- 点击扇区或列表行锁定；再次点击同一项、点击页面空白或按 Esc 取消。Hover 其他目标只暂时覆盖锁定状态，移开后恢复。
- 数据快照更新时按目标 ID 保留点击锁定，目标消失或周期改变时清除。切页、隐藏、卸载时关闭 PopTip，取消排队定位，移除原生窗口钩子与模型订阅。
- 动画约 140ms，使用固定的基础扇区进行命中测试，避免扇区浮起后边缘反复进出、抖动。遵循系统关闭界面动画的设置。

## 界面与实现

- 保持现有主窗口尺寸、导航、日历、目标页及创建/编辑目标弹窗。新总览使用三张等宽卡片，使用统一 30 DIP、1.8 DIP 线宽的橙色线性时钟、绿色线性圆形勾和蓝色线性柱形图，均无底色色块；左图标、右侧上下排列的标签与数值整体垂直居中，保留说明、背景、圆角与数据绑定；下方为橙色渐变柱状图、左环形图/右目标列表。圆环中心从上到下显示“总专注时长”、时长主值及余下分钟，主值限制宽度并仅向下缩放，避免挤压环形区域。
- 默认窗口下六个目标完整显示；目标更多或可用高度更小时使用现有细滚动条，不横向裁切。
- 图表使用 WPF 绘制，柱子不创建逐点控件，环形几何缓存并冻结，画刷与画笔可跨 Dispatcher 安全共享；动画仅在激活状态变化时运行。
- 复用现有 PoptipChrome、Typography 和细滚动条。旧“今日专注”专属弹窗、事件、命令、转换器、旧范围下拉、旧趋势图及旧分布组件已删除；对应测试由新统计/图表/联动回归替代。
- 本地存储协议中的历史月目标数据仍兼容保留，不删除用户已有数据。首页专注结果统计改由明确的历史变更事件刷新，不再依赖已删除的“今日专注”显示属性。
