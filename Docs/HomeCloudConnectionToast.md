# 首页云端连接状态提示

首页顶部新增常驻的断线提示：浅橙背景、16 DIP 圆角、轻阴影、橙色云端断开图标和左侧强调线。标题“未连接云端”，说明“无法连接网络，记录将保存在本地，恢复后自动同步”。没有关闭按钮，也不自动消失。

提示高 54 DIP，使用首页原有的 62 DIP 顶部留白，距两侧各 40 DIP。它不改变准备标题、专注按钮、时长、目标选择或当前屏蔽的位置；隐藏时首页恢复原样。

## 检测

复用 `CloudAccountClient` 的 HttpClient 和 `FOCUSTIME_API_BASE_URL`，向该服务器的 `health/ready` 发起无需登录的异步请求。只有 HTTP 200 且返回 `status: healthy` 才视为可用；数据库未就绪、服务器错误、超时、网络异常、无效响应均视为失败。探测单次超时 4 秒，不改变账号请求的原有超时，也不读写账号凭证。

窗口首帧显示后开始检测，通常每 15 秒一次。可能发生状态切换时，3 秒后复核：连续两次失败才显示，连续两次成功才隐藏；中间相反的结果会重置计数。初始未知状态不提前提示。请求不重叠，退出时取消正在进行的请求和后续轮询。

界面在原来的 UI 上下文更新，不要求手动刷新。检测独立于本地服务、专注计时和记录保存，不更改本地专注流程。连接恢复后，已有同步协调器继续按自身的周期和重试策略处理已归属记录；提示隐藏不表示记录已经同步完成。
