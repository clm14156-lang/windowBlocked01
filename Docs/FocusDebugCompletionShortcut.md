# 专注结算测试快捷键

Debug 构建中，在主窗口的专注页面按 `Ctrl+W`，直接结束当前专注并显示结算页，跳过结束确认弹窗；不足 5 分钟也可用于查看结算效果。

结算使用实际已专注时长、当前任务完成情况和当前主题，沿用提前结束的记录与统计流程，不把剩余时间计入已投入时长。重复按键不会重复结算。

普通专注和本地强制专注通过现有状态机结算。服务持有的强制专注先调用已有 Debug 结束接口，待后台完成会话并释放访问控制后显示结算；后台未连接时不伪造结束状态。

快捷键仅绑定到主窗口，首页未开始、准备阶段、其他页面及结算页不执行。Release 构建不包含此测试入口。原有全局 `Ctrl+W` 调试提醒绑定已移除；`Ctrl+Q` 和 `Shift+Q` 原有入口保留。
