# 设置页面开发提示词

请继续基于现有项目开发“设置”页面。

要求：

* 点击左侧边栏“设置”按钮后，切换到设置页面。
* 当前设置页面为空，请严格参考提供的设置页面参考图，还原基础 UI 布局和视觉样式。
* 现阶段**只实现 UI 和基础前端交互，不实现任何真实业务功能**。
* 需要实现：

  * 设置项布局
  * 开关滑块的开启/关闭状态切换
  * Hover、点击等基础交互反馈
  * “导出记录”“关于应用”等入口的基础点击状态即可，暂不接业务逻辑
* 尽可能还原参考图中的字体、间距、尺寸、圆角、分割线、图标位置、颜色和层级。
* 不要修改现有侧边栏、首页或其他已完成页面。
* 当前可使用临时 Icon、假数据和占位内容。
* 完成后检查页面切换和交互是否影响现有布局及功能。

目标：先完成一个**高还原、可交互的设置页面前端 UI**，后续再逐项接入真实业务功能。
