# ThemePanel_UI_NOTES

## 目标

实现首页“主题”按钮对应的 ThemePanel 浮层。

本阶段只做 **UI + 前端交互**，使用假数据和临时资源，不接服务器。

## 参考图

`Design\\References\\HomePage\\首页_皮肤弹窗.png`

* ThemePanel 尺寸：**450 × 480**
* 严格按参考图高还原实现，参考图为唯一视觉标准。
* 未提供具体组件尺寸时，根据参考图的像素比例和相对位置反推组件尺寸、间距、字体、图标、圆角、颜色和对齐关系。
* 禁止自行优化、重新设计或使用默认 UI 尺寸。
* 缺少图片/Icon 时使用占位资源，但不得改变原有位置、尺寸和比例。

目标：**实现效果与参考图同尺寸叠加时，主要布局和组件尽可能重合。**

## 交互流程

```text
点击 Windows 右上角衣服按钮
    ↓
显示 ThemePanel
    ↓
选择主题
    ↓
更新选中状态
    ↓
首页立即预览
    ↓
点击 × / 点击弹窗外部
    ↓
隐藏 ThemePanel
```

## 交互规则

* ThemePanel 默认隐藏。
* 点击主题后立即预览。
* 当前主题显示选中状态。
* 再次打开时保留当前选择。
* 支持 Hover、选中、关闭状态。

## 内容

* 纯色主题
* 渐变主题
* 个性主题

## 本阶段不做

* 不接服务器和云端数据。
* 不寻找最终 Icon 和主题图片。
* 不实现正式资源管理。
* 不修改首页其他 UI 和布局。

后期 UI 精修阶段统一替换正式 Icon、主题图片和视觉资源。
