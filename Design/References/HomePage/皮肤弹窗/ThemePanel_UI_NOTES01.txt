# ThemePanel 开发提示词

请继续基于现有首页开发 `ThemePanel` 皮肤选择浮层，并**尽可能最大程度还原参考图中的皮肤选择弹窗界面**。

要求：

* `ThemePanel` 窗口尺寸固定为 **420×450**。
* 首页已经完成，**不要重构、重做或修改现有首页布局和功能**。
* 点击首页右上角衣服按钮显示 `ThemePanel`。
* 严格参考皮肤选择弹窗参考图，还原整体布局、间距、字体、圆角、卡片尺寸、选中状态、颜色和视觉层级。
* 通过**截图 + 叠图对比**反复校正，每次修改后重新截图检查差异，直到主要元素尽可能与参考图重合。
* 完整实现显示/隐藏、Hover、选中状态、主题切换预览等前端交互。
* 点击浮层外部区域时自动关闭。
* 当前阶段只使用**假数据、临时 Icon 和占位资源**。
* 不接服务器，不实现正式主题资源管理。
* 开发完成后检查是否影响现有首页布局和功能。

## 主题资源目录

主题资源必须独立管理，采用：

`Assets/Themes/分类/主题名/`

例如：

```text
Assets/
└─ Themes/
   ├─ Solid/
   │  ├─ Orange/
   │  ├─ Blue/
   │  ├─ Cyan/
   │  └─ Dark/
   ├─ Gradient/
   │  ├─ Warm/
   │  ├─ Sky/
   │  ├─ Dream/
   │  └─ Fresh/
   └─ Personal/
      ├─ Starry/
      ├─ Mountain/
      ├─ Forest/
      ├─ Snow/
      └─ Moon/
```

规则：

* 一个主题一个独立文件夹。
* 每个主题自己的预览图、背景图、图标等资源都放在自己的文件夹内。
* 当前没有正式资源的地方统一使用占位图。
* 默认橙色主题直接使用 `Assets/Themes/Solid/Orange/`。
* 主题只负责资源和配置，**不要为不同主题复制首页或业务代码**。
* 目录结构要方便后续直接替换和增加正式主题资源。
